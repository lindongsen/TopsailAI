# Daily work

Review the scheduler project and report anything that needs attention.

## Steps

1. Read `docs/Design.md` and confirm the implementation still matches it.
2. Run `make check` and report any failure.
3. Summarize open items from `.task/` and `issues/`.
4. Write the summary to the run output.

## Done when

The summary names every failing check, or states that all checks pass.
